1. WebStorage APIs are used to store data into the browser. They are usually in the form of key-value pairs
2. Two types of popular webstorage are - sessionStorage, localStorage
3. localStorage --> stores about 5mb, exists until browser is open
4. sessionStorage --> stores about 4kb, exists until session is open
5. WebStorage uses SAME ORIGIN policy for security of the data -
    a. Threee things, protocol(P), host(H), port
    b. EXAMPLE: Consider the source, http://akshaysaini.in
    c. http://akshaysaini.in/data.php --> we can access data since same P, H
    d. https://akshaysaini.in --> we cannot access data because of the different P
    e. http://blog.akshaysaini.in --> we cannot access data because of the different H
    f. http://akshaysaini.in: 8080 --> we cannot access data because of the different Port
